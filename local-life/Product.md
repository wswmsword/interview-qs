前端：
- Next.js
- Tailwind CSS
- Shadcn UI
- Phosphor Icon

实现一个本地生活服务页面，页面属于“墨尔本-装修服务”主题。

页面内容从上到下包括商户名称、商户信息、简介、FAQ。

商户名称作为页面的标题，使用 h1；商户信息是一个左右结构表格，左边是商户信息中的一条信息的 key，右边是 value，这个板块有 h2 标题“商户信息”，但是样式隐藏，保持辅助设备可访问，并且允许 seo 抓取；简介模块有 h2 标题“简介”，内容为用户自定义内容，最后是 FAQ 板块，标题为 h2“FAQ”，内容引入 shadcn 的 Accordion 组件，展示常见问题和解答。

商户信息是个左右结构的表格，展示一个商家的核心元信息，字段包括：地区和区域/服务类别/公司名称/公司地址/公司网址/服务项目/姓名/电话/微信/邮箱。表格无需使用 table 组件，使用 grid 布局即可，保证键的这一列有同样的宽度。

页面顶部是 fixed 定位的导航栏，导航栏中包括左侧 icon、icon 右侧搜索框，以及导航栏右侧的“发布”、“登录”按钮，无需实现具体功能。搜索框的宽度占满了从 icon 右侧到“发布”按钮左侧的宽度。

在正文（商户名称及以下内容）之上是面包屑，体现了当前的网站路径。

面包屑之上的页面头部，是 grid 布局的所有本地生活主题，这些主题包括类似“美食”、“景点/周边游”、“酒店/民宿”、“休闲/玩乐”、“美发”、“外卖”、“KTV”、“健身/运动”、“按摩/足疗”、“装修服务”，“物流搬运”、“园艺绿化”、“水管电工”、“保姆月嫂”、“房屋租赁”。使用网格展示这些主题，每个网格包含 icon 和文字，icon 都使用占位符表示。网格以两行展示，并且在这个板块的左右两侧有左箭头和右箭头按钮，当一页展示不完的时候，通过左右按钮翻页。网格为多列两行，关于网格的尺寸，高度为 120px，宽度动态变化，宽度最小为 120px，将屏幕继续拖动变宽，每个网格的宽度将宽度平分，当变宽的总宽度达到 120px 的时候，新增一列，同样，当减少的宽度达到 120px 的时候，减少一列。

页面使用版心布局，最大宽度为 1024px，主要内容为 1024px，两边添加 padding，保留两边空隙，要注意 navbar 和下方主要内容的最大宽度保持一致。

为页面添加结构化数据，包括 LocalBusiness、Service 和 BreadcrumbList。页面的实现要注意 HTML 语义化标签的使用

页面通过 next.js 的 SSG 生成，在打包的时候，请求后端接口，获取“墨尔本-装修服务”下的商家数据，包括商户名称、商户信息、简介、FAQ，并且在打包期间生成结构化数据和站点地图 sitemap。

后端：
django

使用 django 搭建简单的接口服务，无需使用数据库，数据使用硬编码，允许跨域，使用 Django REST framework 响应 json 数据。实现一个接口 `/details`，接口响应商户名称、商户信息、简介、FAQ，响应格式如下：

```json
{
  "name": "商户名",
  "info": { "地区和区域": "...", "电话": "..." },
  "intro": "...",
  "faq": [{ "question": "...", "answer": "..." }]
}
```
